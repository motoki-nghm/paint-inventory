## テンプレート

```
## [ADR-XXX] タイトル

- **日付:** YYYY-MM-DD
- **ステータス:** proposed / accepted / deprecated / superseded
- **決定者:** エージェント名
- **コンテキスト:** なぜこの決定が必要だったか
- **決定内容:** 何を選んだか
- **理由:** なぜそれを選んだか
- **トレードオフ:** 採用しなかった選択肢とその理由
- **影響範囲:** どのコンポーネント/モジュールに影響するか
```
